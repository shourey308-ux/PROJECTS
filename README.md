# GEMA Competition Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing GEMA Competition registration data for 2025 and 2026. It includes data preparation, cleaning, comparative analysis, trend analysis, and preparation of datasets for Power BI visualization.

The objective is to organize registration data, identify trends, compare performance across years, and generate meaningful insights through data analysis.

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Microsoft Excel
- Power BI
- Data Cleaning & Transformation
- Data Visualization

- Organizing and preparing competition registration datasets.
- Cleaning and processing data for analysis.
- Comparing registration data between 2025 and 2026.
- Analyzing monthly registration trends.
- Comparing registration activity over the last four weeks.
- Preparing structured data for Power BI reporting.

## 🎯 Project Objective

To transform raw competition registration data into organized, analysis-ready datasets and support data-driven decision-making through comparative analysis and visualization.
